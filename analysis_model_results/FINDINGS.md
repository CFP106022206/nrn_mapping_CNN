# 結論與支撐數據

所有數字出自 `results/`。FC = FlyCircuit，EM = hemibrain。中位數 [四分位距]；
AUC 為該描述子單獨使用時的可分離度（0.5 = 隨機）；p 為 Mann-Whitney U 雙尾。

**NBLAST 分數一律為 `run_nblast_official.py` 的輸出**（navis + 官方 `smat.fcwb`，
dotprops k=5、1 µm 重採樣、雙向平均且自比對正規化）。

**所有腦區佔比的分母一律含 `other`**（= `volume`，即完整的 tracing 點數），也就是「佔該神經總重建量的百分之多少」。
程式已不再計算排除 other 的版本。

**標籤二值化**：所有分析一律以專家信心 **≥ 0.5** 為正例（`study_config.py` 的 `POS_CONF`），與論文及出圖程式一致；舊規則（> 0.5）的差異見 §7。

## 1. 兩組的起源與 D1 的解剖身分

兩組的 EM 候選都由 stage-1 prescreening（`candidate_matching.py`：
質心距離 ≤ 100 µm、轉動慣量比 (r21,r31) 距離 ≤ 0.4、rod/disk 主軸一致）產生，再由人工標注。
差別只在 FC 神經的挑選條件：D1 限定 MB 佔比高的 FC 神經；D2 沒有這個前提，挑到的恰好都是
cable 較長的神經。（篩選後到人工標注之間還有一步縮減候選的步驟待補記，見 §4 末與 §9。）

### D1 的主腦區（`s06`）

| 條件 | D1 (n = 103) | D2 (n = 147) |
|---|---|---|
| **主腦區為 MB 或 DFP** | **98.1 %**（101） | 34.0 %（50） |
| 　主腦區為 MB | 61.2 %（63） | **0.0 %**（0） |
| 　主腦區為 DFP | 36.9 %（38） | 34.0 %（50） |
| MB ≥ 5 % | 97.1 % | 22.4 % |
| MB 在前兩名 | 97.1 % | 15.0 % |
| MB 或 DFP 在前兩名 | 100.0 % | 51.0 % |
| MB 或 DFP 任一 ≥ 5 % | 100.0 % | 60.5 % |
| MB 與 DFP 皆 ≥ 5 % | 92.2 % | 21.8 % |
| 前兩名剛好是 {MB, DFP} | 85.4 % | 13.6 % |
| 主腦區種類數 | **4** | **12** |

D1 中位佔比：MB 34.8 %、DFP 31.4 %、合計 68.4 %。前兩名 compartment 在同一半腦者
90.3 %（D2 82.3 %，差距不大，不是 D1 的特徵）。**注意**：仍有 8.7 % 的 D1 第二腦區佔比 < 10 %，
不能說「全部都跨兩腦區」。

主腦區不是 MB 或 DFP 的 2 顆，都仍有不少 MB：

| 神經 | 主腦區 | MB 佔比 |
|---|---|---|
| `VGlut-F-300680` | EB | 27.1 % |
| `VT43401-F-700002` | LH | 17.0 % |

**DFP 本身不區分兩組，區分兩組的是 MB。** 以 DFP 為主的比例兩組幾乎一樣（36.9 % vs 34.0 %），
但這些神經的 MB 分布差很多：

| 主腦區為 DFP 的神經 | D1 (n = 38) | D2 (n = 50) |
|---|---|---|
| 同時 MB ≥ 5 % | **92.1 %** | 48.0 % |
| MB 佔比中位 | **31.0 %** | 4.5 % |

建議寫法：用「主腦區為 MB 或 DFP」描述 D1 本身；需要與 D2 對照時，補一句
「97.1 % 的 D1 神經有 ≥ 5 % 的神經突位於 MB（D2 為 22.4 %）」。

「皆 ≥ X %」與「任一 ≥ X %」的門檻敏感度（D1 / D2）：

| 門檻 | 任一 | 皆 |
|---|---|---|
| 1 % | 100.0 / 72.1 | 97.1 / 42.9 |
| 5 % | 100.0 / 60.5 | 92.2 / 21.8 |
| 10 % | 100.0 / 50.3 | 84.5 / 12.9 |
| 20 % | 98.1 / 42.9 | 67.0 / 4.8 |

「皆 ≥ 5 %」的 5 % 為人為選定，且暗示「兩區都要有」，比挑選條件更強，不建議當標題。

### D1 的用詞：可以說「經過」，不能說「從 MB 出發」

| 用詞 | 可否 | 理由 |
|---|---|---|
| 經過 / have neurites in / arborize in | ✅ | 資料量的就是神經突落在哪 |
| innervate | ⚠️ | 領域慣用，但嚴格來說暗示有突觸，骨架量不到 |
| 從 MB 出發 / originate from | ❌ | soma 位置與投射方向都不在這份資料裡 |
| 全部都跨 MB 與 DFP | ❌ | 皆 ≥ 5 % 只有 92.2 %；另有 8.7 % 的第二腦區佔比 < 10 % |
| 同側投射 | ❌ | 前兩名 compartment 同半腦者 D1 90.3 %、D2 82.3 %，不是 D1 的特徵 |

### D1 不是嗅覺 projection neuron

草稿句 *These projection neurons are important, especially for the olfactory system.* 會讓讀者以為
D1 是嗅覺 PN。果蠅嗅覺 PN 的經典路徑是 **AL → MB calyx → LH**，因此檢查這三個腦區（分母含 other）：

| 腦區 | D1 中位 | D1 ≥ 5 % | D2 中位 | D2 ≥ 5 % |
|---|---|---|---|---|
| MB（不含 calyx） | 34.8 % | 97.1 % | 0.7 % | 22.4 % |
| DFP | 31.4 % | 95.1 % | 9.4 % | 59.9 % |
| **AL** | 0.0 % | **0.0 %** | 0.0 % | 16.3 % |
| **Calyx** | 0.0 % | **1.0 %** | 0.0 % | 0.7 % |
| **LH** | 0.0 % | **5.8 %** | 0.1 % | 16.3 % |

1. **D1 沒有嗅覺 PN 的型態**：103 顆中 AL ≥ 5 % 的 0 顆、calyx ≥ 5 % 的僅 1 顆。D1 的 MB 神經突在
   calyx 以外，另一端在 DFP，較符合 MB extrinsic neurons（如 MBON、DAN）的型態，但本分析判定不了細胞型別。
2. **D2 也不以嗅覺 PN 為主**：D2 有 24 顆 AL ≥ 5 %，其中 calyx ≥ 5 % 的是 0 顆，較像侷限在 AL 內的神經。
   `GH146-M-000001` 名稱帶有經典 PN driver，實際分布卻是 AL 75.3 %、calyx 0.0 %、LH 2.0 %，不是 PN 的投射型態。
3. **projection neuron 的定義看連接，不看大小**：指軸突離開樹突所在的 neuropil、投射到另一區域的神經元，
   相對於整棵留在同一區內的局部中間神經元。最大跨度判定不了——大型局部中間神經元的跨度可以超過連接
   兩個相鄰區域的 PN，而且跨度不含「哪一端是輸入」的資訊。本資料最接近的代理是「cable 分布在兩個分開的
   腦區」（第二 compartment 佔比，§2），只能說形態上符合投射型。果蠅文獻中單講 projection neurons 幾乎
   專指嗅覺 PN，建議從 D1 的描述中拿掉這個詞。

替代寫法：*The MB is a well-established center for olfactory learning and memory, which makes
MB-associated neurons a natural starting point.*

### D1 的標題候選

- `Sub-dataset D1: Neurons with the MB or DFP as the primary neuropil`
- `Sub-dataset D1: MB-associated neurons`

DFP = dorsofrontal protocerebrum（細分為 SDFP / IDFP）。MB↔DFP 的細胞型別歸屬
（MBON / DAN 等）本分析無法判定，需另行確認（§9）。

## 2. 形態差異的主軸是**大小**

| 描述子 | D1 | D2 | AUC | p |
|---|---|---|---|---|
| Cable length, FC | 1 722 µm | **4 817 µm** | **0.905** | 4e-28 |
| Cable length, EM | 2 318 µm | **6 584 µm** | 0.819 | 2e-26 |
| Branch points, FC | 74 | **230** | 0.886 | 1e-25 |
| 第二 compartment 佔比, FC（`sidetot_top2`） | **0.251** | 0.136 | 0.846 | 1e-20 |

`cable_length`、`n_branch_points`、`n_tips`、`occupied_volume` 相互 Spearman
**≥ 0.96**，是**同一個大小軸**。扣除 cable 長度後，分支數的殘餘判別力僅 AUC 0.569
（FC，p = 0.063），且方向相反（D1 每單位 cable 的分支略多）。

**佔位拓撲是第二條獨立軸**：`sidetot_top2` AUC 0.846，依 cable 長度 1:1 配對後
（±25 %，40 對）仍有 **0.804**。組內 log(cable) 與佔位分散度的相關 |ρ| ≤ 0.30。
`sidetot_top2` = 佔比第二大的 compartment（左右分開計）佔總 tracing 點數（`volume`，含 other）的比例，
數值越小代表越集中在單一 compartment。

**D2 的主腦區分布**（共 12 種；D1 只有 4 種：MB 61.2 %、DFP 36.9 %、EB 與 LH 各 1 顆）：

| DFP | AL | VLP | DLP | FB | LH | EB | SPP | DMP | CCP | CMP | LOB |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 34.0 % | 16.3 % | 12.9 % | 12.2 % | 12.2 % | 4.1 % | 2.7 % | 2.0 % | 1.4 % | 0.7 % | 0.7 % | 0.7 % |

**可引用的納入條件**（`s07`）。只看一顆 FC 神經的形態，用一條門檻規則判斷它屬於 D1 還是 D2
（共 250 顆：D1 103、D2 147）。這與 MorphoMatcher、NBLAST 的配對表現**無關**，目的是給論文一條
讀者可以重新套用的量化規則。

- **Balanced accuracy** =（D2 判對比例 + D1 判對比例）/ 2，0.5 = 隨機。兩組人數不同（147 vs 103），
  用它避免「全部猜 D2 也有 59 % 準確率」的假象。
- **交叉驗證**：10 等分 × 重複 10 次，門檻在每個訓練 fold 內重擬合，報平均 ± 標準差，不是擬合準確率。

| 規則（判為 D2） | CV balanced accuracy | precision / recall |
|---|---|---|
| **cable ≥ 2 474 µm** | **0.871 ± 0.066** | — |
| cable ≥ 2 000 µm 且 `sidetot_top2` ≤ 0.244 | 0.861 ± 0.068 | 0.905 / 0.905 |
| cable ≥ 2 398 µm 且 `regiontot_top2` ≤ 0.369 | 0.854 ± 0.072 | 0.909 / 0.884 |
| 只用 `sidetot_top2` ≤ 0.190 | 0.748 ± 0.068 | — |
| logistic：cable + `sidetot_top2` + `arbor_separation` | 0.878（AUC 0.934） | — |

**cable 長度單獨就是最好的明確規則**，加入佔位集中度不會更準（0.861 < 0.871）。佔位拓撲的價值在於它是
獨立的第二條軸，不在於提升分類。舊版報告的 `cable ≥ 2 000 µm 且 side_top2 ≤ 0.32` → 0.881
用的是不含 other 的分母，已停用。

## 4. ⭐ 失效機制：hemibrain 側的「海綿效應」

NBLAST 對 query 的每個點取 target 的最近鄰計分。**當 target 是填滿緊緻體積的高密度
樹突叢時，query 的任何一點都能找到近鄰，分數被結構性推高**，與形狀是否相符無關。

海綿效應需要兩個條件同時成立：**線材夠密**，且**縮在夠小的範圍**（才會整團壓在
query 上）。因此最能捕捉它的指標是把兩者合在一起量的**凸包密度**。

### 主要證據：凸包密度 `cable_per_hull_um2` = 總 cable 長度 / 凸包體積（µm/µm³）

D2 的 383 組非配對中，NBLAST 分數與 **hemibrain 側**凸包密度的 Spearman
**ρ = +0.634**（p = 1.8e-44）。依此四等分：

| 四分位 | 假配對分數中位 | **達真配對水準的比例** |
|---|---|---|
| 1（最稀疏） | 0.012 | **1.0 %** |
| 2 | 0.099 | 12.2 % |
| 3 | 0.184 | 21.7 % |
| 4（**最密**） | **0.308** | **67.7 %** |

（真配對分數中位 0.335）**最稀疏 1.0 %、最密 67.7 %。**

**穩健性**：凸包對離群分支敏感是常見疑慮，但實測不成立——剔除距質心最遠的
1 / 5 / 10 % cable 後重算，ρ 為 +0.638 / +0.646 / +0.636（完整凸包 +0.633），
各版本相關 0.94–0.99，凸包體積中位僅縮小 4 %。

`fill_ratio`（佔用體積 / 凸包體積，無量綱）給出幾乎相同的結果：ρ = +0.637，
1.0 % → 65.6 %。它純粹在量「這團有多實心」，可作為佐證。

### 次要證據：佔用格密度 `revisit_r16um`

= 總 cable 長度 /（被佔用的 16 µm 格子數 × 16 µm）。無單位，**1.0 = 每格恰被
直直穿過一次**。它只量「神經實際碰到的空間有多擠」，不含凸包的形狀資訊。

ρ = **+0.585**（p = 1.6e-36），四分位 **1.0 % → 61.5 %**。

兩者在 EM 神經間相關 0.785——**相關但不等同**，凸包版多出來的正是「形狀緊緻度」，這也是它
預測力較高的原因（+0.634 vs +0.585）。`revisit` 的價值在於它**不依賴凸包假設**，
因此作為敏感度分析：結論不隨密度的定義方式改變。

多尺度佐證：`revisit_r4um` +0.502、`revisit_r8um` +0.535、`revisit_r16um` +0.585
——訊號隨尺度單調增強，細尺度（1–2 µm）因 cable 幾乎不重複經過同一格而飽和。

### 效應以 hemibrain 側為主，而且是 **target 端**的性質

D2 假配對，Spearman ρ：

| 描述子 | **EM 側 ρ** | FC 側 ρ |
|---|---|---|
| **`cable_per_hull_um2`** | **+0.634** | +0.496 |
| `fill_ratio` | +0.637 | +0.499 |
| **`revisit_r16um`** | **+0.585** | +0.196 |
| `revisit_r8um` | +0.535 | +0.075 (n.s.) |
| `revisit_r4um` | +0.502 | +0.052 (n.s.) |
| `overdraw_2d_mean` | +0.547 | +0.137 |
| `hull_volume_um3` | **−0.432** | −0.457 |
| `cable_length_um` | +0.359 | −0.056 (n.s.) |

`hull_volume` 的負號（凸包越小分數越高）正是「緊緻」這一半條件的直接體現。

FC 側的 +0.496 **不能直接讀成「FC 也有海綿效應」**：兩側密度本身相關 +0.501
（prescreening 會把形態相近的送作堆）。四項檢驗釐清誰是主因（s10 第 (9) 區塊，
輸出 `sponge_fc_side.csv`）：

| 檢驗 | EM | FC |
|---|---|---|
| 偏相關（控制另一側） | **+0.513** (p=4e-27) | +0.266 (p=1e-07) |
| 秩迴歸標準化係數 | **+0.515** | +0.238 |
| 限制在兩側共同密度區間 | **+0.434** | +0.159 |

**方向檢驗**是最直接的證據。`include_inverse` 檔案存有分方向的原始分數
（forward = query FC → target EM；inverse = query EM → target FC），交換方向後
主導側跟著換：

| 方向 | EM 偏相關 | FC 偏相關 |
|---|---|---|
| forward（target = EM） | **+0.582** | +0.127 |
| inverse（target = FC） | +0.348 | **+0.325** |

FC 的獨立貢獻從 +0.13 升到 +0.33（2.6×），EM 從 +0.58 掉到 +0.35。**海綿效應
是 target 端的密度造成的，不是某個資料庫的特性。**（真配對更乾淨：forward
EM +0.380 / FC −0.092，inverse EM +0.011 / FC **+0.232**，完全翻轉。）

那為什麼實務上仍然只在 EM 端發動？兩個結構性原因：

1. **動態範圍**：D2 假配對牽涉的神經，EM 密度 P90/P10 = **9.69×**（最大
   0.0656），FC 只有 **3.53×**（最大 0.0141）。全體 FC 的 P99 是 0.0135，
   而 **16.3 % 的 EM 神經比它更密**——光學重建解析不出的密度，EM 有。
2. **即使拉平範圍，EM 仍勝**：只看兩側都落在 FC 的 5–95 百分位區間內的 227 組，
   EM +0.434 vs FC +0.159。所以不只是量程問題。

D1 的 FC 側是**相反號**（−0.623，比 D2 任何一個數字都大）：投射型的緊緻 FC
query 對上位置不重疊的 EM target 時，幾乎全是孤兒點 → 極負分；伸展開的反而
有機會蹭到。那是孤兒點機制，不是海綿（見下方孤兒點分析）。

### 因果鏈的直接證明：密度 → 孤兒點 → 分數

孤兒點（query 的點在 target 半徑 10 µm 內找不到近鄰）是 NBLAST 負分的直接來源，
四個子集裡它與分數的相關都在 **ρ ≈ −0.91 ~ −0.94**——這是所有描述子裡最強的。
海綿效應的因果鏈應該是「target 密 → query 的點都找得到近鄰 → 孤兒點少 → 分數高」。

`s10` 第 (7) 區塊現在**雙向**計算孤兒率：

- `orphan_fwd` = FC 的點在 EM 找不到近鄰（**target = EM**）
- `orphan_rev` = EM 的點在 FC 找不到近鄰（**target = FC**）

D2 假配對呈現**雙重解離**：

| 密度 | 原始 ρ | 控制 `orphan_fwd` | 控制 `orphan_rev` | 密度 → 對應孤兒率 |
|---|---|---|---|---|
| **EM** | +0.635 | **+0.114**（幾乎全消） | +0.633（完全不動） | −0.654 |
| **FC** | +0.498 | +0.344（幾乎不動） | **+0.243**（大幅消） | −0.448 |

每一側的密度**只透過「自己當 target 的那個方向」的孤兒率**發揮作用，另一個方向
的孤兒率動不了它。這同時證明了兩件事：(1) 海綿效應的機制確實是「壓低孤兒點」，
(2) 它是 **target 端**的性質。真配對重現同樣的型態（EM +0.382 → +0.173 / +0.380）。

D1 假配對則不同：EM 密度 → `orphan_fwd` 只有 **+0.213**（號還是相反的），因為
D1 的非配對根本不在同一個位置（孤兒率中位 **98.7 %**，NN 中位 45.07 µm）。
密度再高也吸不到不在附近的點——**海綿要先接觸得到才吸得動**。


少數 EM 神經成為「hub」，吸走大量假陽性：`1640922516`（19 620 µm cable、
3 558 分支、凸包密度高）單獨吸引 6 組高分假配對；`947573616`（27 778 µm、
6 324 分支）4 組。

### 已排除的競爭解釋

| 解釋 | 檢驗 | 結論 |
|---|---|---|
| D2 的負例被 prescreening 篩得比較難 | 兩組非配對通過三層篩選的比例 **89.0 % (D1) vs 93.5 % (D2)** | ❌ 不成立 |
| D1 的 EM 池密度比較均勻 | 變異係數 **0.536 (D1) vs 0.528 (D2)**，95/5 分位比 3.4× vs 4.1× | ❌ 不成立 |
| 雙向平均 / 自比對正規化可消除 | forward ρ +0.667 → 雙向平均 +0.640 → 官方 +0.634 | ❌ 幾乎無效果 |

**自比對正規化為何無效**：`S(A,A)` 只與 query 有關，完全不涉及 target，而偏差來自
target 端。可能的修正方向是對 target 也正規化（除以其對隨機神經的期望分數）。

### D1 為何免疫：孤兒點替它把工作做完了

**不是因為 D1 的 EM 池比較均勻**（變異係數 0.536 vs 0.528，幾乎相同），而是
**D1 的非配對根本不在同一個位置**：

| | 真配對 NN 中位 | **假配對 NN 中位** | 假配對 >10 µm 孤兒點 |
|---|---|---|---|
| **D1** | 5.75 µm | **45.07 µm** | **98.7 %** |
| **D2** | 6.10 µm | **9.31 µm** | 46.9 % |

關鍵在於**孤兒點對 D1 是好事**。它幾乎完全決定分數（D1 ρ = −0.935、D2 ρ = −0.918），
而 D1 的非配對 98.7 % 是孤兒點，分數因此一律被壓到很負（中位 −0.605），真假兩堆
自動分開——**替 NBLAST 把工作做完了**。D2 的非配對 NN 中位 9.31 µm，跟真配對的
6.10 µm 幾乎一樣近，**沒有孤兒點可以幫忙排除**，NBLAST 只能靠形狀分辨，海綿效應
才在這裡發動。

量化這件事：把孤兒率單獨拿來當分類器，**幾乎複製了 NBLAST 的整個表現**——

| | NBLAST AUC | 只用 −孤兒率 | 控制孤兒率後 NBLAST 的殘餘鑑別力 |
|---|---|---|---|
| **D1** | 0.954 | **0.942** | ρ +0.783 → **+0.239** |
| **D2** | 0.834 | **0.819** | ρ +0.574 → **+0.202** |

**在本資料上，NBLAST 一階近似就是在量「兩顆神經的點雲有沒有空間重疊」，形狀只是
二階修正。** 對論文的意義：D1 的 0.954 主要來自非配對候選本身在空間上就離得遠，**不能當成 NBLAST
形狀鑑別力的證據**。

反過來看海綿效應：D1 的 EM 密度 → `orphan_fwd` 只有 **+0.213**（號還是相反的），
密度再高也吸不到不在附近的點。**海綿要先接觸得到才吸得動**——空間共位是海綿效應
的前提條件，D2 滿足而 D1 不滿足，這就是效應只在 D2 發動的完整解釋。

⚠️ **必須揭露（已更正）**：D1 與 D2 的負例**產生方式相同**——都是先以 prescreening 產生 EM 候選，
再由人工標注。兩組的差別在 **FC 神經的挑選條件**：D1 限定 MB 佔比高的 FC 神經；D2 沒有這個前提，
挑到的恰好都是 cable 較長的神經。因此 D1 非配對在空間上較遠（NN 中位 45.07 µm vs D2 9.31 µm），
是**同一套篩選套用在兩個不同族群上的結果**，屬於族群性質，而不是負例挑選方式的產物。
上面「孤兒率單獨就有 AUC 0.942」量化的正是 D1 非配對的這種空間分離。

佐證（`D5_conf.csv`，label ≥ 0.5 為正例）：D1 負例的質心距離中位 79.2 µm、p95 99.8 µm，
95.8 % ≤ 100 µm——恰好被 prescreening 的 100 µm 門檻截住；若是人工另挑的遠距負例，不會
出現這個截斷。D1 真配對的質心距離中位為 14.7 µm。

仍需揭露的限制：(1) 兩組 FC 神經依不同條件選出，D1 與 D2 的直接比較反映的是兩個族群的差異；
(2) 質心＋ratio 篩選後每顆 FC 神經仍有數千個候選（D1 中位 3 909），但 D1 每顆只標注 ≤ 2 個、
D2 ≤ 5 個，且被標注的 EM 並非質心最近者（D1 中位排名 195，僅 2.8 % 在前兩名）。從數千縮到
2／5 個的步驟（推測為當時的模型排序）**待補記**；若兩組在這一步用了不同的排序方式或 k 值，
它仍可能影響負例難度。海綿效應本身在 D2 內部獨立成立，不依賴這個跨組比較。

### MorphoMatcher 並排：海綿效應是 NBLAST 特有的（`s12`）

同樣 898 組配對、同一份標籤（專家信心 **≥ 0.5** 為正例），描述子與分箱定義同上。MorphoMatcher
的分數取自 10-fold 交叉驗證的測試預測（每組配對只由沒訓練過它的 fold 模型打分）；改用 fold 內
百分位重算，結論不變。

| | D1 AUC | D2 AUC | D1 → D2 |
|---|---|---|---|
| NBLAST | 0.954 | 0.834 | −0.120 |
| **MorphoMatcher** | **0.993** | **0.969** | **−0.024** |

**D2 假配對的分數 vs 資料性質**（Spearman，n = 383；粗體 = p < 0.001）：

| 描述子 | NBLAST | MorphoMatcher |
|---|---|---|
| EM 凸包密度 | **+0.634** | −0.095 |
| EM 凸包密度，控制 EM cable | **+0.563** | −0.082 |
| EM cable，控制 EM 凸包密度 | −0.068 | +0.013 |
| EM 凸包密度，控制 FC 凸包密度 | **+0.513** | −0.070 |
| FC 第二 compartment 佔比 | **−0.217** | +0.096 |
| 孤兒率（空間不重疊） | **−0.918** | −0.015 |

依 EM 凸包密度四等分，D2 假配對達真配對水準（≥ 該方法真配對分數的 25 % 分位）的比例：

| 四分位 | NBLAST | MorphoMatcher |
|---|---|---|
| 1（最稀疏） | 1.0 % | 2.1 % |
| 2 | 12.2 % | 1.0 % |
| 3 | 21.7 % | 2.2 % |
| 4（**最密**） | **67.7 %** | **0.0 %** |

hub：NBLAST 的 98 組高分假配對分布在 66 顆 EM，吸引力與 EM 密度 ρ = +0.680（p = 1.9e-11），
`1640922516`、`1762359683`、`947573616` 各吸 4–6 組；MorphoMatcher 只有 5 組高分假配對、分在 5 顆
EM，與密度無關（ρ = −0.073，p = 0.54），NBLAST 的 hub 一顆都沒有出現。ROC 操作點上兩者的假陽性
幾乎不重疊（NBLAST 100、MorphoMatcher 35，共同 5）。

**結論：D2 對 NBLAST 困難，來自 NBLAST 的最近鄰計分遇上密集 target，而不是 D2 的配對本身無法分辨。**
EM 密度只有在「密度 → 找得到近鄰 → 高分」這條機制下才會變成假陽性；MorphoMatcher 的三視圖以
各神經自身的包圍盒正規化、沒有最近鄰比對，這條路徑不存在。控制 cable 後 NBLAST 的密度效應仍在
（+0.563），控制密度後 cable 的效應消失（−0.068）——推高 NBLAST 分數的是密度，不是大小。

**MorphoMatcher 在 D2 剩下的困難在另一條軸：大小。** 它對大型神經的真配對給分偏低（D2 真配對分數
vs FC cable ρ = −0.273、EM cable −0.253，p < 0.001），漏判的真配對也偏大、偏密（FN vs TP 的 AUC：
FC cable 0.681、EM cable 0.676、EM 密度 0.660，n_FN = 24）；D1 的神經小，這個關係不存在（FC cable
ρ = −0.079）。一個可能的解釋是大型 arbor 縮進 50 × 50 影像後細節被壓縮，**尚未驗證**；密度與 cable
互相控制後各自都不顯著（−0.127 / −0.156），在這裡兩者分不開。

⚠️ D1 的 MorphoMatcher 分數仍與孤兒率相關（假配對 −0.390、真配對 −0.414，控制 EM 密度後不變）。
模型看不到位置，這個相關只能經由形狀：D1 裡空間上不重疊的候選同時也長得不一樣，兩者在 D1 分不開。
因此 D1 的高表現可以寫成「模型以形狀分辨」，但不能寫成「D1 的候選在形狀上難以區分」。

## 5. 人工判定用 soma，而 NBLAST 看不到

| | 真配對 | 假配對 | AUC | p |
|---|---|---|---|---|
| **D2** | **36.3 µm** | 109.1 µm | **0.798** | 1.1e-40 |
| D1 | 74.5 µm | 161.4 µm | 0.713 | 6.9e-08 |

在 98 組 NBLAST 分不開的 D2 配對中，soma 距離的 AUC 為 **0.773**（p = 5.4e-16）；
D1 的 6 組則無效（0.549, p = 0.70）。

**加入 soma 後的交叉驗證 AUC**（5-fold × 20）：

| | NBLAST | soma | **NBLAST + soma** | 增益 | 錯誤率變化 |
|---|---|---|---|---|---|
| D1 | 0.9530 | 0.7133 | 0.9517 | −0.0014 | **+2.9 %** |
| **D2** | 0.8340 | 0.7978 | **0.8888** | **+0.0548** | **−33.0 %** |

**NBLAST 為何用不到 soma**：等權求和下，以 1 µm 重採樣後 soma 10 µm 鄰域僅佔點雲的
**0.24 %（D2）與 0.72 %（D1）**——絕對點數兩組幾乎相同（12 vs 13），差別全在分母。
骨幹同樣被稀釋：最高 Strahler 階的 cable 佔比 D2 為 2.9 %（FC）與 2.2 %（EM），
D1 為 5.4 % 與 6.0 %；而骨幹的**絕對**長度在 EM 上兩組幾乎相同（149.5 vs 146.7 µm，
1.02×），總 cable 卻差 2.84×。

⚠️ **不能寫成劑量反應**：D2 組內依 cable 長度四等分，NBLAST 的 AUC 為
0.607 → 0.877 → 0.894 → 0.884（最短的一箱最差）。**cable 越長 NBLAST 反而越好**，
因此「D2 的 cable 長所以 soma 被稀釋所以 NBLAST 差」這條因果鏈**不成立**。
稀釋是**與大小無關的結構性盲點**，不是錯誤率的驅動因素。

## 6. 論文可用的論證骨架

1. D1 限定 MB 佔比高的 FC 神經，解剖同質（98.1 % 的主腦區為 MB 或 DFP，僅 4 種主腦區）；
   D2 無此前提（兩組的 EM 候選皆由 prescreening 產生後人工標注），橫跨 12 個主腦區。
2. 兩組形態上的主要差異是神經突總長度（2.8×，兩個資料庫一致），加上一條獨立的
   佔位拓撲軸；局部密度、自我重疊、形狀各向異性在控制大小後皆不成立。
3. 官方 NBLAST 在 D2 上 precision 僅 0.697（D1 為 0.918），25.6 % 的非配對達到
   真配對水準。
4. 主因是 hemibrain 側的海綿效應：非配對分數與 EM 凸包密度 ρ = **+0.634**，最密
   四分位 **67.7 %** 的非配對達真配對水準（最稀疏僅 1.0 %）。佔用格密度給出同向
   但較弱的結果（+0.585），顯示結論不依賴密度的定義方式。已排除 prescreening
   強度與候選池密度變異兩個解釋。
5. **這是 NBLAST 特有的**：MorphoMatcher 在同一組配對上 D2 AUC 0.969（NBLAST 0.834），假配對分數與
   EM 密度無關（ρ −0.095 vs +0.634），最密四分位 0 % 的假配對達真配對水準（NBLAST 67.7 %）。它在 D2
   剩下的困難是大型神經的真配對給分偏低（ρ ≈ −0.27），與密度無關（§4 末）。
6. 人類以 soma 位置排除這些案例（在混淆案例中 AUC 0.773），而 NBLAST 給 soma
   的權重僅 0.24 %。加入 soma 使 D2 錯誤率下降 33 %，D1 無變化。
7. MorphoMatcher 以 Strahler 階加權使 soma 與初級神經突取得最高權重，正是為了
   取用這個 NBLAST 結構上無法表達的線索。
