# 結論與支撐數據

所有數字出自 `results/`。FC = FlyCircuit，EM = hemibrain。AUC 為該描述子單獨使用時的可分離度
（0.5 = 隨機）；p 為 Mann-Whitney U 雙尾。

- **NBLAST 分數**一律為 `run_nblast_official.py` 的輸出（navis + 官方 `smat.fcwb`，dotprops k=5、
  1 µm 重採樣、雙向平均且自比對正規化）。
- **腦區佔比的分母一律含 `other`**（= `volume`，完整 tracing 點數），即「佔該神經總重建量的百分之多少」。
- **標籤二值化**一律以專家信心 **≥ 0.5** 為正例（`study_config.py` 的 `POS_CONF`），與論文及出圖程式一致。

## 1. 兩組的起源與 D1 的解剖身分

兩組的 EM 候選都由 stage-1 prescreening（`candidate_matching.py`：質心距離 ≤ 100 µm、
轉動慣量比 (r21,r31) 距離 ≤ 0.4、rod/disk 主軸一致）產生，再由人工標注。差別只在 FC 神經的
挑選條件：**D1 限定 MB 佔比高的 FC 神經；D2 沒有這個前提**，挑到的恰好都是 cable 較長的神經。
（篩選後到人工標注之間還有一步縮減候選的步驟待補記，見 §4 末與 §10。）

### D1 的主腦區（`s06`）

| 條件 | D1 (n = 103) | D2 (n = 147) |
|---|---|---|
| **主腦區為 MB 或 DFP** | **98.1 %**（101） | 34.0 %（50） |
| 　主腦區為 MB | 61.2 % | **0.0 %** |
| 　主腦區為 DFP | 36.9 % | 34.0 % |
| MB ≥ 5 % | **97.1 %** | 22.4 % |
| MB 與 DFP 皆 ≥ 5 % | 92.2 % | 21.8 % |
| 主腦區種類數 | **4** | **12** |

D1 中位佔比：MB 34.8 %、DFP 31.4 %。主腦區不是 MB / DFP 的 2 顆仍有不少 MB
（`VGlut-F-300680` 主 EB、MB 27.1 %；`VT43401-F-700002` 主 LH、MB 17.0 %）。

**DFP 本身不區分兩組，區分兩組的是 MB。** 以 DFP 為主的比例兩組幾乎一樣（36.9 % vs 34.0 %），
但這些神經同時 MB ≥ 5 % 的比例是 **92.1 % vs 48.0 %**，MB 佔比中位 **31.0 % vs 4.5 %**。

建議寫法：用「主腦區為 MB 或 DFP」描述 D1 本身；需要與 D2 對照時補一句「97.1 % 的 D1 神經有
≥ 5 % 的神經突位於 MB（D2 為 22.4 %）」。「皆 ≥ 5 %」的門檻為人為選定且暗示「兩區都要有」，
比實際挑選條件更強，不建議當標題。

### D1 的用詞：可以說「經過」，不能說「從 MB 出發」

| 用詞 | 可否 | 理由 |
|---|---|---|
| 經過 / have neurites in / arborize in | ✅ | 資料量的就是神經突落在哪 |
| innervate | ⚠️ | 領域慣用，但嚴格說暗示有突觸，骨架量不到 |
| 從 MB 出發 / originate from | ❌ | soma 位置與投射方向都不在這份資料裡 |
| 全部都跨 MB 與 DFP | ❌ | 皆 ≥ 5 % 只有 92.2 %；另有 8.7 % 的第二腦區佔比 < 10 % |
| 同側投射 | ❌ | 前兩名 compartment 同半腦者 D1 90.3 %、D2 82.3 %，不是 D1 的特徵 |

### D1 不是嗅覺 projection neuron

草稿句 *These projection neurons are important, especially for the olfactory system.* 會讓讀者
誤以為 D1 是嗅覺 PN。經典嗅覺 PN 路徑為 **AL → MB calyx → LH**：

| 腦區 | D1 中位 | D1 ≥ 5 % | D2 中位 | D2 ≥ 5 % |
|---|---|---|---|---|
| MB（不含 calyx） | 34.8 % | 97.1 % | 0.7 % | 22.4 % |
| DFP | 31.4 % | 95.1 % | 9.4 % | 59.9 % |
| **AL** | 0.0 % | **0.0 %** | 0.0 % | 16.3 % |
| **Calyx** | 0.0 % | **1.0 %** | 0.0 % | 0.7 % |
| **LH** | 0.0 % | **5.8 %** | 0.1 % | 16.3 % |

D1 的 103 顆中 AL ≥ 5 % 為 0 顆、calyx ≥ 5 % 僅 1 顆——MB 神經突在 calyx 以外、另一端在 DFP，
較符合 MB extrinsic neurons（MBON / DAN）的型態，但本分析判定不了細胞型別。D2 也不以嗅覺 PN
為主（24 顆 AL ≥ 5 % 者 calyx ≥ 5 % 為 0）；`GH146-M-000001` 雖帶經典 PN driver 名稱，分布卻是
AL 75.3 %、calyx 0.0 %、LH 2.0 %。

此外 projection neuron 的定義看**連接**不看大小，最大跨度判定不了；果蠅文獻中單講 projection
neurons 幾乎專指嗅覺 PN，建議從 D1 的描述中拿掉這個詞。替代寫法：*The MB is a well-established
center for olfactory learning and memory, which makes MB-associated neurons a natural starting point.*

**標題候選**：`Sub-dataset D1: Neurons with the MB or DFP as the primary neuropil` /
`Sub-dataset D1: MB-associated neurons`。DFP = dorsofrontal protocerebrum。

## 2. 形態差異的主軸是**大小**

| 描述子 | D1 | D2 | AUC | p |
|---|---|---|---|---|
| Cable length, FC | 1 722 µm | **4 817 µm** | **0.905** | 4e-28 |
| Cable length, EM | 2 318 µm | **6 584 µm** | 0.819 | 2e-26 |
| Branch points, FC | 74 | **230** | 0.886 | 1e-25 |
| 第二 compartment 佔比, FC（`sidetot_top2`） | **0.251** | 0.136 | 0.846 | 1e-20 |

`cable_length`、`n_branch_points`、`n_tips`、`occupied_volume` 相互 Spearman **≥ 0.96**，是**同一個
大小軸**。扣除 cable 長度後分支數的殘餘判別力僅 AUC 0.569（p = 0.063），方向還相反。

**佔位拓撲是第二條獨立軸**：`sidetot_top2` AUC 0.846，依 cable 長度 1:1 配對後（±25 %，40 對）
仍有 **0.804**；組內 log(cable) 與佔位分散度的相關 |ρ| ≤ 0.30。數值越小代表越集中在單一 compartment。

**可引用的納入條件**（`s07`）：只看一顆 FC 神經的形態，用門檻規則判斷它屬於 D1 還是 D2（250 顆）。
與配對表現無關，目的是給論文一條可重新套用的量化規則。Balanced accuracy 為兩組判對率的平均
（避免「全猜 D2 也有 59 %」的假象），10 等分 × 重複 10 次交叉驗證、門檻在訓練 fold 內重擬合。

| 規則（判為 D2） | CV balanced accuracy |
|---|---|
| **cable ≥ 2 474 µm** | **0.871 ± 0.066** |
| cable ≥ 2 000 µm 且 `sidetot_top2` ≤ 0.244 | 0.861 ± 0.068 |
| 只用 `sidetot_top2` ≤ 0.190 | 0.748 ± 0.068 |

**cable 長度單獨就是最好的明確規則**，加入佔位集中度不會更準。佔位拓撲的價值在於它是獨立的
第二條軸，不在於提升分類。

**標題候選**：`Sub-dataset D2: Large, regionally confined neurons across the brain`。
**不建議在標題用 dense**——控制大小後「D2 整體比 D1 密」不成立（§8）；海綿效應講的是 D2 **內部**
的密度差異。

## 4. ⭐ 失效機制：hemibrain 側的「海綿效應」

NBLAST 對 query 的每個點取 target 的最近鄰計分。**當 query 所在的空間裡塞滿 target 的 cable，
query 的任何一點都找得到近鄰，分數被結構性推高**，與形狀是否相符無關。

### ⭐ 關鍵實驗：有效密度（`s10` 第 (10) 區塊 → `sponge_effective_density.csv`）

**有效密度** = 落在 FC query 凸包**內**的 EM cable 長度 ÷ FC query 凸包體積（µm/µm³）

與凸包密度同一個定義，只是改在 **query 的範圍內**量 target，把「target 密不密」與「密在不在
query 那裡」合成一個數。純幾何量，不經過 NBLAST 計分。

| | D1 | D2 |
|---|---|---|
| 真配對的有效密度（中位） | 0.0087 | 0.0116 |
| **非配對的有效密度（中位）** | **0.0003** | **0.0119** |
| 非配對有效密度 = 0 的比例 | 42.4 % | 0.0 % |
| **以有效密度區分真／假配對的 AUC** | **0.846** | **0.517** |
| 非配對達到真配對水準的比例 | 5.1 % | 25.1 % |
| NBLAST AUC | 0.954 | 0.834 |

**D2 滿足海綿效應的條件，D1 不滿足。** D2 的非配對在 query 所在空間裡的 target 密度**與真配對一樣高**
（AUC 0.517，等於亂猜），最近鄰計分無從分辨；D1 的非配對近乎 0（42 % 在 query 範圍內連一點 target
cable 都沒有），真假天然分開。

**同一條曲線解釋兩組。** 非配對（兩組合併）依有效密度四等分：

| 四分位 | 有效密度 | D1 / D2 組數 | 達真配對水準 |
|---|---|---|---|
| Q1 | 0 – 0.0027 | 79 / 47 | 0.0 % |
| Q2 | 0.0028 – 0.0087 | 22 / 103 | 1.6 % |
| Q3 | 0.0088 – 0.0175 | 14 / 111 | 19.2 % |
| Q4 | 0.0179 – 0.170 | 3 / 122 | **60.8 %** |

D1 的非配對 67 % 落在 Q1，D2 的 61 % 落在 Q3–Q4；組內相關 D1 ρ = +0.894、D2 ρ = +0.756。以「非配對會不會
達到真配對水準」為目標，只用有效密度的 5-fold AUC = **0.920**，加入組別後 **0.919**：
**知道有效密度之後，D1／D2 的標籤不再帶任何資訊。**

**為什麼不能只看 target 自身的密度**：D1 的 EM target 其實**比 D2 更密**（非配對中位 0.0083 vs 0.0060，
p = 2e-4；整份 EM 名單 0.0069 vs 0.0053）。單用它的 AUC 只有 0.810，在 D1 內部甚至反向（ρ = −0.263）。
D2 的 cable 長 2.84 倍、凸包大 2.93 倍，相除後反而略稀。**關鍵不是「target 密」，而是「密在 query 那裡」。**

有效密度與孤兒率（query 的點在 target 10 µm 內找不到近鄰）ρ = −0.84，兩者是同一件事的兩面：一個從
target 量，一個從 query 量。有效密度的好處是沿用凸包密度的定義，而且完全不經過 NBLAST。

### 其他結果（精簡）

- **MorphoMatcher 沒有這個效應**（`s12`）：同一批配對，D1 / D2 AUC 0.993 / 0.969（NBLAST 0.954 / 0.834）；
  D2 假配對分數與 EM 凸包密度 ρ = −0.095（NBLAST +0.634），最密四分位 0 % 達真配對水準（NBLAST 67.7 %）。
  它在 D2 剩下的困難在大小：大型神經的真配對給分偏低（vs FC cable ρ = −0.273），原因**尚未驗證**。
- **D2 內部的劑量反應**：假配對分數與 EM 凸包密度 ρ = +0.634，四分位 1.0 → 67.7 % 達真配對水準；換成
  `fill_ratio`（+0.637）或不依賴凸包的 `revisit_r16um`（+0.585）結論不變；剔除最遠 1 / 5 / 10 % cable 後
  ρ = +0.638 / +0.646 / +0.636。
- **效應在 target 端**：交換 query / target 後主導側跟著換；控制 target 端孤兒率後密度效應消失
  （EM +0.635 → +0.114），控制另一端則不動（雙重解離，`s10` (7)(9)）。
- **已排除**：prescreening 把 D2 篩得比較難（非配對通過率 89.0 % vs 93.5 %）；EM 池比較均勻（變異係數
  0.536 vs 0.528）；雙向平均或自比對正規化可修正（ρ +0.667 → +0.634，`S(A,A)` 不涉及 target）。

### ⚠️ 必須揭露

D1 與 D2 的負例**產生方式相同**：都是先以 prescreening 產生 EM 候選再人工標注，差別在 FC 神經的挑選條件。
D1 非配對在空間上較遠，是同一套篩選套用在兩個族群上的結果，而不是另挑遠距負例。佐證（`D5_conf.csv`）：
D1 負例質心距離中位 79.2 µm、p95 99.8 µm，95.8 % ≤ 100 µm，恰好被 prescreening 的門檻截住。

仍需揭露：(1) 兩組 FC 神經依不同條件選出，跨組比較反映的是兩個族群的差異；(2) 質心＋ratio 篩選後每顆
FC 仍有數千個候選（D1 中位 3 909），但 D1 每顆只標注 ≤ 2 個、D2 ≤ 5 個，且被標注的 EM 並非質心最近者
（D1 中位排名 195）。從數千縮到 2／5 個的步驟**待補記**（§10）。海綿效應本身由有效密度一個變數解釋，
兩組服從同一條曲線，不依賴跨組比較。

## 5. 人工判定用 soma，而 NBLAST 看不到

| | 真配對 | 假配對 | AUC | p |
|---|---|---|---|---|
| **D2** | **36.3 µm** | 109.1 µm | **0.798** | 1.1e-40 |
| D1 | 74.5 µm | 161.4 µm | 0.713 | 6.9e-08 |

在 98 組 NBLAST 分不開的 D2 配對中，soma 距離的 AUC 為 **0.773**（p = 5.4e-16）；D1 的 6 組則無效。

**加入 soma 後的交叉驗證 AUC**（5-fold × 20）：

| | NBLAST | soma | **NBLAST + soma** | 增益 | 錯誤率變化 |
|---|---|---|---|---|---|
| D1 | 0.9530 | 0.7133 | 0.9517 | −0.0014 | **+2.9 %** |
| **D2** | 0.8340 | 0.7978 | **0.8888** | **+0.0548** | **−33.0 %** |

**NBLAST 為何用不到 soma**：等權求和下，以 1 µm 重採樣後 soma 10 µm 鄰域僅佔點雲的
**0.24 %（D2）與 0.72 %（D1）**——絕對點數兩組幾乎相同（12 vs 13），差別全在分母。骨幹同樣被
稀釋：最高 Strahler 階的 cable 佔比 D2 為 2.9 %（FC）/ 2.2 %（EM），D1 為 5.4 % / 6.0 %，而骨幹的
**絕對**長度在 EM 上兩組幾乎相同（149.5 vs 146.7 µm），總 cable 卻差 2.84×。

⚠️ **不能寫成劑量反應**：D2 組內依 cable 長度四等分，NBLAST 的 AUC 為 0.607 → 0.877 → 0.894 → 0.884
（最短的一箱最差）。**cable 越長 NBLAST 反而越好**，「D2 的 cable 長 → soma 被稀釋 → NBLAST 差」
這條因果鏈**不成立**。稀釋是與大小無關的結構性盲點，不是錯誤率的驅動因素。

## 6. 論文可用的論證骨架

1. D1 限定 MB 佔比高的 FC 神經，解剖同質（98.1 % 的主腦區為 MB 或 DFP，僅 4 種主腦區）；D2 無此
   前提（兩組的 EM 候選皆由 prescreening 產生後人工標注），橫跨 12 個主腦區。
2. 兩組形態上的主要差異是神經突總長度（2.8×，兩個資料庫一致），加上一條獨立的佔位拓撲軸；
   局部密度、自我重疊、形狀各向異性在控制大小後皆不成立。
3. 官方 NBLAST 在 D2 上 precision 僅 0.697（D1 為 0.918），25.6 % 的非配對達到真配對水準。
4. 主因是 hemibrain 側的海綿效應，觸發條件是 **query 所在空間裡的 target 密度（有效密度）**。D2 的非配對
   有效密度與真配對一樣高（區分真假的 AUC 0.517），D1 的近乎 0（AUC 0.846）；兩組服從同一條曲線（非配對
   四分位 0.0 → 60.8 % 達真配對水準），知道有效密度之後組別不再帶資訊（AUC 0.920 → 0.919）。target 自身的
   密度反而是 D1 較高：關鍵不是 target 密，而是密在 query 那裡。已排除 prescreening 強度與候選池密度變異。
5. **這是 NBLAST 特有的**：MorphoMatcher 在同一組配對上 D2 AUC 0.969，假配對分數與 EM 密度無關
   （ρ −0.095），最密四分位 0 % 達真配對水準。
6. 人類以 soma 位置排除這些案例（在混淆案例中 AUC 0.773），而 NBLAST 給 soma 的權重僅 0.24 %。
   加入 soma 使 D2 錯誤率下降 33 %，D1 無變化。
7. MorphoMatcher 以 Strahler 階加權使 soma 與初級神經突取得最高權重，正是為了取用這個 NBLAST
   結構上無法表達的線索。

## 7. 草稿需修正之處

**D1 的神經數**：`D5_conf.csv` 為 216 組配對、**109 FC / 143 hemibrain**。草稿寫的
「150 in FC and 153 in hemibrain」不正確（150 是 D2 的 FC 數）。**D2**：682 組、150 FC / 349 hemibrain，已核對無誤。

**正負例數隨二值化寫法改變**（信心度恰為 0.5 的配對會從負例變成正例）：

| | > 0.5（舊規則） | ≥ 0.5（現行） | 恰為 0.5 |
|---|---|---|---|
| D1（`D5_conf`） | 94 / 122 | **98 / 118** | 4 |

## 9. 身分洩漏（identity leakage）檢驗（`s13`）

交叉驗證以**配對**為單位切分，同一顆神經可以同時出現在訓練集與測試集（只是配在不同的對象上）。
成對任務裡這稱為 identity / entity leakage。標註神經數有限，做不到兩側都不重疊的切分，因此這裡
不宣稱沒有管道，而是量出管道大小，再檢驗模型有沒有依賴它。

**管道有多大**（1 219 組測試配對）：FC 側 **86.1 %**、EM 側 **68.5 %** 曾出現在同折訓練集，兩側都
出現 60.3 %，**兩側都沒出現只有 5.7 %（69 組）**。捷徑的上限：完全不看影像，只用「該神經在訓練集
的正例比例」預測測試標籤——FC 先驗 AUC 0.739、EM 0.825、兩側平均 **0.848**（模型本身 0.978）。
身分本身就帶有大量標籤資訊，所以「有沒有被利用」必須實測。

### 證據 1：沒看過的神經，模型表現一樣好

| 分層 | n | AUC | 95 % CI |
|---|---|---|---|
| **兩側都沒看過** | 69 | **0.955** | [0.905, 0.990] |
| 只有 FC 看過 | 315 | 0.977 | [0.962, 0.990] |
| 只有 EM 看過 | 100 | 0.996 | [0.987, 1.000] |
| **兩側都看過** | 735 | **0.979** | [0.970, 0.987] |

差距（兩側都沒看過 − 兩側都看過）**−0.024，95 % CI [−0.075, +0.013]**，跨過 0。「訓練時見過該 FC
神經的正確伴侶」與否也沒有差別（0.976 vs 0.983），不支持「記住伴侶長相」。

### 證據 2：先驗必定給錯時，模型仍然判對

| 案例 | n | 模型判對 |
|---|---|---|
| 假配對，但該 FC 神經在訓練集多為正例 | 159 | 89.3 % |
| 假配對，但該 EM 神經在訓練集多為正例 | 103 | 89.3 % |
| 真配對，但該 FC 神經在訓練集多為負例 | 103 | 84.5 % |
| 真配對，但該 EM 神經在訓練集多為負例 | 60 | 71.7 % |
| 對照：全體 | 1 219 | 92.9 % |

先驗在這些案例上是 0 % 正確，模型仍有 72–89 %：**它會覆蓋先驗，不是跟著先驗走。**

### 證據 3：預訓練管道，下游量不到影響

pseudo-label 的標籤是 **10 個 annotator fold 模型預測的平均**，那組模型合起來看過全部專家標註，
而十折微調都從同一個預訓練模型出發——**預訓練階段不是 fold-clean**。排除只做在**配對**層級：
與專家標註的共同配對為 **0**，但共同神經有 FC 392/453（86.5 %）、EM 447/587（76.1 %），涉及被標註
神經的 pseudo-label 有 **12 876 組（7.2 %）**。

依「測試配對的神經有沒有進過 pseudo-label 名單」分層：

| 分層 | n | AUC | 95 % CI |
|---|---|---|---|
| 兩側都沒進預訓練 | 32 | 0.978 | [0.927, 1.000] |
| 只有一側進了 | 381 | 0.980 | [0.968, 0.991] |
| 兩側都進了 | 806 | 0.977 | [0.969, 0.985] |

### 證據 4：annotator 的記憶沒有以會造成洩漏的形式外溢

annotator 對自己訓練過的專家配對有預期內的擬合優勢（AUC 0.990 vs 留出的 0.933），但**記憶本身不等於
洩漏**——要造成洩漏，它得以「壓低同一顆神經的其他候選」的形式外溢，因為只有那些其他候選會進入
pseudo-label。

分折以**配對**為單位：對 (X, Y) 這組專家配對，9 個模型看過「這組配對及其信心度」、1 個沒看過，但 X
的其他配對是獨立分散在各折的。因此只取**所有專家配對都落在同一折**的神經（對它們而言，那一折的
模型完全沒看過它的任何標註），再依「有沒有正例配對」分開——只有「知道正確伴侶」才對應到該假設。

| 側 | 該神經的標註 | 神經數 | n | 不知情 − 知情 |
|---|---|---|---|---|
| FC | 有正例（知道正確伴侶） | 117 | 1 155 | **−0.030**（p 1.5e-22） |
| FC | 只有負例 | 30 | 353 | **+0.050**（p 2.5e-09） |
| FC | 對照：未標註 + 隨機折 | — | 213 761 | +0.000（p 0.64） |
| EM | 有正例 | 171 | 4 911 | −0.002（p 0.09） |
| EM | 只有負例 | 181 | 4 409 | +0.009（p 2.8e-11） |

**假設不成立**：知道 X 的正確伴侶時，知情模型對 X 的其他候選反而給得**更高**（差為負），方向與
「壓低」相反——比較像是從正例學到「X 容易配對」，那會製造更多假陽性而非幫忙排除。真正存在的是
幅度 0.01–0.05 的**每顆神經標籤先驗**。而且 `predict_std < 0.05` 的篩選把受影響最深的配對濾掉大半
（FC 有正例：−0.030 → −0.012）；真正進入預訓練名單、又存在完全不知情對照模型因而測得準的，只有
**30 組**。（別與 7.2 % 混淆：7.2 % 是總曝光，30 組是可乾淨測量的子集。）

### 限制與應該怎麼寫

- ✅ 可以寫：目前的數字不太可能主要來自洩漏（上述四項證據）。
- ❌ 不能寫：這個切分**無法證明**模型能推廣到沒見過的神經——完全未見的測試配對只有 69 組、未進
  預訓練的只有 32 組，CI 寬達 ±0.04。**只能說沒看到影響，不能說證明沒有。**
- ⚠️ 唯一的殘留訊號：同一真實標籤內，分數仍與 EM 側先驗相關（真配對 ρ +0.562、假配對 +0.231）。
  這**不能直接當成記憶的證據**——形態清楚、容易配對的神經本來就同時有高的訓練正例率與高的模型
  分數，兩者與難易度混淆，本分析無法分離。
- 論文**必須明講**切分方式：pair-level 10 折交叉驗證，神經可跨折重複出現。

### 已修正的流程缺口

「配對層級交集 = 0」是**手動**達成的：`EMxFC_6KK_last.csv` 由 `preTrain_label/Annotator_D1-D6_*.csv`
拼出後人工剔除了專家配對，但這個動作沒有寫進 pipeline，而且只擋專家配對本身、擋不住「同一顆
神經的其他候選」——記憶正是經由後者外溢。現已補上 `make_pseudo_candidates.py`：在十折 annotator
預測**之前**，把任一側為人工標註神經的配對整批剔除（6 482 684 → **5 937 816** 組，剔除 8.40 %），
並在 `merge_pseudo_label.py` 尾端加了把關。詳見 `MODEL_PIPELINE_HANDOVER.md` §7.0。
**現有模型與論文數字仍出自舊流程**，要讓預訓練真正 fold-clean 需重跑（§10）。

## 10. 外部型別驗證：annotator 在全庫檢索上優於 fine-tune

分析程式與資料在 `analysis_external_validation/`，判定標準完全獨立於本專案的 CNN：
FC 端用 Virtual Fly Brain 的 FBbt 策展型別，EM 端用 neuPrint `hemibrain:v1.2.1` 的 `type`。
取型別能明確對應 hemibrain 的三個族群（LC 視覺投射、Kenyon cell、嗅覺投射神經），
得到 **2 735 顆 FC / 25 341 筆配對**——這些 FC **沒有一顆進過專家標註**。

### 結果與測試集相反

只算「正解確實有進 stage-1 候選池」的 1 276 顆 FC（隨機基準 3.16 %）：

| 模型 | rank-1 命中 | top5 命中 | rank-1 確定錯誤 |
|---|---|---|---|
| fine-tune | 22.0 % | 23.7 % | 59.1 % |
| **annotator** | **31.0 %** | **32.5 %** | **46.1 %** |

McNemar 配對檢定 **p = 8.8e-10**。分族群看，差距**完全來自 Kenyon cell**：

| 族群 | n | fine-tune | annotator | p | 結論 |
|---|---|---|---|---|---|
| KC | 846 | 18.1 % | **32.2 %** | 1.6e-12 | annotator 顯著較佳 |
| LC | 241 | 44.9 % | 42.0 % | 0.42 | 無顯著差異 |
| ALPN | 138 | 3.6 % | 2.9 % | 1.0 | 無顯著差異，兩者都近乎無效 |

兩份掃描分別由 `FineTune_miniLR_D1-D6_0` 與 `Annotator_D1-D6_0` 產生
（見 `nrn_service/config.py`）。而在十折測試集上，**同一個 `FineTune_miniLR` 10/10 折全勝**
（整體 AUC **0.9784** vs 0.9293，平均 ΔAUC **+0.046**）。

### fine-tune 的分類優勢是真的，在完全未見的神經上仍成立

`analysis_external_validation/unseen_stratum.py` 依 `s13` 的定義重算四個模型在各分層的
AUC 並附 bootstrap CI（`results/unseen_stratum.csv`）。「兩側神經都沒進訓練集」那一層：

| 模型 | n | AUC | 95 % CI |
|---|---|---|---|
| annotator | 69 | 0.887 | [0.790, 0.961] |
| FineTune180K_miniLR | 69 | 0.916 | [0.841, 0.971] |
| **FineTune_miniLR** | 69 | **0.955** | [0.905, 0.990] |

配對 bootstrap（同一批 69 組）：`FineTune_miniLR − annotator` 的 **ΔAUC = +0.068，
CI [+0.001, +0.146]，P(Δ>0) = 0.976**。n 只有 69、CI 很寬，但方向與全測試集一致。

**所以不能把 fine-tune 的測試集優勢歸因於洩漏。** 它在二分類任務上確實比較好，
包括對沒見過的神經。

### 機制：兩個假設被實驗否證，第三個成立

分析與資料在 `analysis_hubness_debias/`。這一節經過三輪修正，前兩輪都寫錯過，
過程本身值得留下：

**第一輪（錯）：全域分數膨脹。** 曾把 rank-1 崩壞歸因於「分數整體膨脹、正確答案被
高分錯誤候選淹沒」。邏輯上不成立——**單一 FC 池內的 rank-1 對分數的任何單調變換都是
不變的**（實測最高分 0.997、無 float ties），全域平移不可能改變排名。
若病灶真是全域平移，一個「免疫於全域平移」的排序損失就沒有東西可修，論證自我抵銷。

**第二輪（錯）：per-EM 偏移（海綿效應）。** 偏移確實存在——全部 22 286 顆 FC 的掃描中，
fine-tune 的 rank-1 只落在 **2 401** 顆不同 EM 上（annotator 3 507），
前 10 名 EM 吃掉 **14.9 %**（annotator 10.8 %）。
但**修正它回收不了差距**（`analysis_hubness_debias/README.md`）：

| 模型 | 基線 rank-1 | 最佳去偏（center α=0.25） | 顯著性 |
|---|---|---|---|
| fine-tune | 21.97 % | 24.58 % | p = 0.055 |
| annotator | 31.01 % | 31.28 % | p = 0.791 |

11 種設定（置中、CSLS、z-score、池內 rank 正規化）× 2 模型 × 2 種基線估計集，
**沒有任何一組讓池內 AUC 上升**；強去偏更是災難性（z-score 讓 rank-1 掉到 0.8 %）。
→ 分數裡的 per-EM 成分**本身帶有真實訊號**，「某些 EM 容易被配上」有一部分是生物事實。
另外也測過「EM 三視圖尺寸」假設（成對 padding 以較大者為準），同樣不成立
（|Spearman rho| < 0.2，且方向矛盾：大 EM 平均分較低卻更常拿 rank-1）。

**第三輪（成立）：head 與訓練目標是瓶頸，表徵不是。**
唯一不受 top-5 條件汙染的量測是**池內 AUC**（每顆 FC 各自算「型別相符 vs 確定不同型」
的 AUC 再平均）：

| 模型 | 池內 AUC | p@5 | 正解 rank 中位 |
|---|---|---|---|
| fine-tune | 0.861 | 53.9 % | 5 |
| annotator | 0.898 | 67.1 % | 3 |

annotator 在整個池的**各個深度**都排得較好，不只是頂端——所以「進場」與「排序」
不是兩件可分的事，只有一個排序，annotator 的整條比較好。

⚠️ 舊版曾據「top-5 內成對正確率 0.476 vs 0.456」主張 fine-tune 在頂端排得較好，
**該主張已撤回**：兩個數字算在幾乎不相交的樣本上（兩模型都評分的三元組只有 **23 組**），
且以 FC 為單位做 cluster bootstrap 後 CI 大幅重疊（[0.445, 0.506] vs [0.427, 0.485]）。
能說的只有「兩者都與擲銅板無異，也彼此無異」。

### 階段 2 探針：卷積特徵夠用，錯的是 head 的訓練目標

⚠️ **「只重訓 head」這個說法容易誤導，參數分布是反過來的：**

| 部分 | 參數量 | 佔比 |
|---|---|---|
| trunk（`Concatenate` 之前：conv1-4 + 6 個 BN，三視圖與兩側共享卷積權重） | 66 528 | **1.4 %** |
| head（`Concatenate` 之後：Dense 18432→256 + BN + Dense 256→1） | 4 720 129 | **98.6 %** |

所以探針凍結的是 **1.4 %** 的參數、重訓的是 **98.6 %**。
結論要說成「**卷積特徵抽取器夠用，不必重訓；問題出在它上面那個佔了絕大多數參數的
分類頭是為錯的目標訓練的**」，而不是「表徵裡藏了很多沒取出的訊號」。

凍結 trunk、重訓 head（InfoNCE，池內挖的型別三元組），
在 held-out 的 638 顆 FC 上：

**必須同時看「EM 先驗」這個虛無模型**——完全忽略 FC、只用每顆 EM 的平均分排序
（先驗用一半 FC 估、另一半評估，樣本外）：

| head | rank-1 | **EM 先驗 only** | KC rank-1 / 其 EM 先驗 |
|---|---|---|---|
| 原 head（基線） | 31.6 % | 7.7 % | 32.2 % / — |
| 重訓（**從頭**，lr 1e-3） | 62.8 % | **7.7 %** | **70.8 % / 0.5 %** |
| 重訓（從現有權重，lr 1e-4） | 63.8 % | **39.4 %** ⚠️ | 67.3 % / **46.6 %** ⚠️ |

⚠️ **「從現有權重」那一版不可採信。** 它的 EM 先驗單獨就有 39.4 %，
**比整個基線模型的 31.6 % 還高**——那 +32 pp 裡有一大塊是「這些 body ID 是好答案」，
不是形態比對。機制很直接：低 lr 從已擬合的 head 出發時，最省力的下降方向就是加一個
全域 EM 偏置，而 InfoNCE 若只從同一顆 FC 的池抽負例，這麼做對損失是**免費的**。

**headline 用「從頭」那一版：KC 上 70.8 %（基線 32.2 %），EM 先驗僅 0.5 %。**
這是乾淨的 FC-conditional 增益，且正落在缺口所在的族群。

**也不是身分記憶**（移除所有訓練正例 EM 後重排，從頭版 Δ +9.6 pp，CI [+0.5, +18.2]），
**也不是粗粒度族群分類**（候選池限縮到同族群 EM 後，增益不減反增）。

⚠️ **分族群的可信度不同**：**KC 可信**（EM 先驗 0.5 %，n = 212）；
**LC 兩個變體都被先驗汙染**（40.0 % / 37.1 %），需標註；
**ALPN 未定**（兩變體 55.9 % vs 21.2 %，n ≈ 34），不寫進結論。

（`check_em_leakage.py` 測的是「身分記憶」，測不到「EM 先驗」——它依賴移除訓練正例後
仍留下的 FC，而每顆 eval FC 的正例中屬於訓練正例的比例中位是 1.00，多數 FC 移除後
就整顆退出檢查了。虛無模型才是抓到這件事的工具。）

⚠️ **池內 AUC 不該當唯一主指標。** ALPN 基線的池內 AUC 是 0.997 但 rank-1 只有 5.8 %，
且從頭版讓 AUC 降到 0.989、rank-1 卻升到 15.9 %——兩指標反向。原因是每顆 FC 的正例數
差兩個數量級（KC 中位 111、ALPN 只有 1），AUC 對全部正例取平均、又看不到未定型候選。
**主指標改用 MRR 與「最佳正解的 rank 中位」，池內 AUC 降為整體分離度的輔助診斷，
且一律分族群報。**

⚠️ **兩個必須揭露的限制：**
- **任務對齊的循環性尚未排除。** 探針用型別標籤訓練、也用型別標籤評估；
  原 head 是用專家**個體層級**標籤訓練的，從未為此優化。
  正確的讀法是「凍結表徵**含有**做型別檢索的資訊，現有 head 沒把它取出來」，
  **不是**「重訓會讓個體層級配對提升 33 pp」。
- **rank-1 的執行間變異約 ±10 pp**（從頭版兩次 52.2 % / 63.2 %，池內 AUC 卻穩定在
  0.947–0.948）。單次的 rank-1 不可過度解讀，**池內 AUC 才是穩健指標**。

（實作陷阱：head 的 `BatchNormalization` 若用預設 `momentum=0.99`，
在探針的步數規模下 moving 統計量嚴重滯後，推論時池內 AUC 會掉到 **0.33**——低於隨機、
系統性反向。必須降到 0.9 並提高每 epoch 的步數。）

### 分數膨脹是另一個問題：門檻不可用

分數膨脹本身是真的，但它傷的是**門檻可用性**，不是排名：

| | 確定不同型（n≈7–8 k） | 型別相符（n≈1.5–2 k） |
|---|---|---|
| fine-tune | 中位 **0.877**，≥0.95 佔 **18.8 %** | 中位 0.960 |
| annotator | 中位 0.776，≥0.95 佔 **1.6 %** | 中位 0.872 |

**操作門檻的後果。** rank-1 是數千個候選的最大值，幾乎不可能低於 0.5
（兩個模型各只有 2 顆 FC，0.2 %），所以低分門檻不做任何過濾；
要拉到 0.9 才看得出差別：

| rank-1 門檻 | fine-tune 有預測 / 命中率 | annotator 有預測 / 命中率 |
|---|---|---|
| 無 | 1 276 (100 %) / 22.0 % | 1 276 (100 %) / 31.0 % |
| ≥ 0.8 | 1 202 (94.2 %) / 22.6 % | 1 101 (86.3 %) / 31.9 % |
| ≥ 0.9 | **1 061 (83.2 %) / 23.7 %** | 489 (38.3 %) / 34.4 % |

fine-tune 對 **83 %** 的 rank-1 給出 ≥ 0.9，其中四分之三是錯的。
而且門檻從無拉到 0.9，命中率只各升 +1.7 / +3.4 個百分點——
**分數在排序頂端幾乎不帶資訊**。以 0.9 當「高信心」門檻在 fine-tune 上不可用。

測試集的組成使它偵測不到這件事：

- `leakage_shortcut.csv`：光靠身分先驗、不看形態就有 AUC 0.848（FC 0.739、EM 0.825）。
- `leakage_overlap.csv`：每折測試配對只有 3–9 % 是兩側神經都沒見過。
- 測試集從未要求模型在數千個候選中排序。

### 為什麼 pseudo labeling 這一段沒有帶來提升

self-training 有效的前提是 cluster assumption（決策邊界落在低密度區）與雜訊注入
（Xie et al., *Noisy Student*, CVPR 2020）；失效機制是 confirmation bias
（Arazo et al., 2020）。本任務兩個前提都不成立：

1. **型別之間不存在低密度邊界。** FBbt 對 LC12 的定義原文即寫「投射到 PVLP 腹側視覺球，
   位於 LC17 內側」；KCab-c / KCab-s 更是連續梯度。
2. **以十折標準差低來篩 high-confidence，選到的是「一致的偏差」而非「正確」。**
   十個模型共享資料與架構，一致同意不代表對。`Cha-F-000004` 是現成例子：
   兩模型共識（`min_score`）把 LC12 推到第一，把兩顆真正的 LC17 壓到第 5 與第 8。
3. 加上 §4 已量到的海綿效應，pseudo label 會系統性偏向萬用 EM，再餵回去正是
   confirmation bias 的教科書情境。

領域內做到規模的跨模態比對（NeuronBridge 的 CDM Search / PatchPerPixMatch、
VFB 的 NBLAST 矩陣、hemibrain↔FAFB 的 `hemibrain_matches`）一律採
「原理明確的相似度函數 + human-in-the-loop」，沒有用自舉式 pseudo label。

### ⚠️ 必須揭露

- 判定只到**型別**層級。hemibrain 有 186 顆 LC17、227 顆 LC12、252 顆 KCab-c，
  型別相符不等於同一顆；`1.0` 應讀成「沒有被排除」。專案的專家標註是**個體層級**
  （每顆 FC 中位數只給 1 顆正例），比型別層級嚴格得多。
- 可評估族群限於型別名稱能對應 hemibrain 的三類，KC 佔 1 638 顆、主導總體數字，
  **必須看分族群的表**。
- 交叉驗證抓到並修掉一個判定 bug（hemibrain 多腎小球 PN 寫成 `M_<譜系><編號>`，
  譜系 token 在字串中間，原本的字尾比對會把 ALl1 譜系全部漏掉，
  誤標 4 筆專家確認的正例）。修正後「確定不同型」14 647 → **14 270** 筆，
  與專家標註**零衝突**；模型比較數字不受影響。
  之後再修掉反方向的寬鬆：VFB 只標「uniglomerular PN」、無譜系可查時，舊規則連 PFNd、
  DNp23 等非投射神經也判「相容」。改為至少要求 EM 同屬 ALPN 後 173 筆 `0.5` → `0.0`
  （**14 443** 筆），全落在不可贏的 FC，上表數字與專家交叉驗證皆不變。
- **rank-1 的分母有兩種口徑**：`31.0 %` 排除「rank-1 落在 hemibrain 未定型 EM」的情形
  （可判定分母），`30.3 %` 把它算進分母（全體分母）。兩種都成立，本文一律用前者，
  引用時須標註。
