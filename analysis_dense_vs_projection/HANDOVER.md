## 0. 背景

專案 `nrn_mapping_CNN` 用 CNN 做果蠅神經的跨資料庫配對——把 **FlyCircuit**（光學
顯微鏡，單神經螢光標記，記為 FC）的神經，對應到 **hemibrain**（電子顯微鏡連接體，
記為 EM）的神經。模型叫 MorphoMatcher。

論文中有兩個人工標註的子資料集，需要在方法章節說明它們**為什麼這樣分**，以及
**為什麼 NBLAST（既有的標準形態比對方法）在其中一組表現較差**。

| 論文代號 | 檔案 | 規模 | 由來 |
|---|---|---|---|
| **D1**（projection 類） | `labeled_info/D5_conf.csv` | 216 組配對 / 109 FC / 143 EM | 以蕈狀體（MB）為錨點人工標定 |
| **D2**（dense 類） | `labeled_info/{D2,D6}_conf.csv`<br>（= `D2+D6_ID.csv`） | 682 組配對 / 150 FC / 349 EM | 以 stage-1 prescreening 自動產生候選後人工確認 |

兩個檔案的 `label` 欄是**專家信心 0–1**（不是二值標籤），下游一律以 `> 0.5` 二值化。

## 1. 問題一：這兩組在形態上到底差在哪？

### 結論：只有兩條軸

| 軸 | 代表指標 | D1 | D2 | AUC (FC / EM) |
|---|---|---|---|---|
| **大小** | 神經突總長度 cable length | 1 722 µm | **4 817 µm** | 0.905 / 0.819 |
| **佔位拓撲** | 第二 compartment 佔總體積比 | **0.325** | 0.162 | 0.884 |

`cable_length`、`branch_points`、`n_tips`、`occupied_volume` 彼此 Spearman **≥ 0.96**
——**是同一條軸，不是四個獨立證據**。扣除 cable 長度後，分支數的殘餘判別力僅
AUC 0.569（p = 0.063），且方向相反。

佔位拓撲是**獨立**的第二條軸：依 cable 長度 1:1 配對（±25 %）後，第二 compartment
佔比仍有 AUC **0.808**（全體 0.884）。

### D1 的解剖身分

| 條件 | D1 (n=103) | D2 對照 (n=147) |
|---|---|---|
| `mb_4` 或 `dfp_5` 在前兩名腦區 | **100.0 %** | 51.0 % |
| **`mb_4` 與 `dfp_5` 各佔總體積 ≥ 5 %** | **92.2 %** | 21.8 % |
| 主腦區種類數 | **4** | **12** |

D1 中位佔比：MB 34.8 %、DFP 31.4 %、合計 68.4 %；93.2 % 為同側投射。
DFP = dorsofrontal protocerebrum。細胞型別歸屬（MBON / DAN 等）本分析無法判定。

> ⚠️ 仍有 8.7 % 的 D1 第二腦區佔比 < 10 %，**不能**說「全部都跨兩腦區」。

### 可引用的納入條件

cable ≥ 2 000 µm **且** 第二 compartment 佔比 ≤ 0.32
→ 交叉驗證 balanced accuracy **0.881 ± 0.071**（precision 0.91 / recall 0.93）。
門檻在每個訓練 fold 內重新擬合，不是擬合準確率。

## 2. 問題二：NBLAST 為什麼在 D2 表現較差？

### NBLAST 的表現（官方 navis + `smat.fcwb`，雙向平均）

| | D1 | **D2** |
|---|---|---|
| AUC | 0.967 | **0.814** |
| **precision** | 0.907 | **0.636** |
| recall | 0.936 | 0.784 |
| 假配對分數中位 | **−0.594** | **+0.170** |
| 非配對達真配對水準的比例 | 4.9 % | **27.3 %** |

專家信心同向：D2 平均 0.634 vs D1 0.776；打 1.0 者 4.5 % vs 21.5 %（p = 7.6e-11）。

### ⭐ 主因：hemibrain 側的「海綿效應」

**NBLAST 對 query 的每個點取 target 的最近鄰計分。當 target 是填滿緊緻體積的高密度
樹突叢時，query 的任何一點都能找到近鄰，分數被結構性推高——與形狀是否相符無關。**

D2 的 414 組假配對中，分數**由 EM 側決定，FC 側幾乎無關**：

| 描述子 | **EM 側 ρ** | FC 側 ρ |
|---|---|---|
| `revisit_r16um`（16 µm 格重複穿越次數） | **+0.574** | −0.052 |
| `overdraw_2d_mean`（三視圖自我遮蔽） | **+0.538** | +0.103 |
| `branch_per_100um` | **+0.519** | +0.099 |
| `hull_volume_um3` | **−0.457** | −0.477 |

依 EM 密度四等分，假配對「達到真配對水準」的比例：

| 箱 | `revisit_r16um` | 假配對分數中位 | **達真配對水準** |
|---|---|---|---|
| 1 | 0.90–1.81 | 0.032 | **3.8 %** |
| 2 | 1.82–2.35 | 0.111 | 10.7 % |
| 3 | 2.36–3.49 | 0.219 | 32.0 % |
| 4 | **3.51–10.88** | **0.310** | **62.5 %** |

**最密與最稀疏的四分位差 16 倍。** 少數 EM 神經成為「hub」：`1640922516`
（19 620 µm cable、3 558 分支）單獨吸引 6 組高分假配對。

### 為什麼 D1 免疫

**不是因為 D1 的 EM 池比較均勻**（變異係數 0.536 vs 0.528，幾乎相同），而是
**D1 的非配對根本不在同一個位置**：

| | 真配對 NN 中位 | **假配對 NN 中位** | 假配對 >10 µm 孤兒點 |
|---|---|---|---|
| **D1** | 5.63 µm | **44.25 µm** | **98.7 %** |
| **D2** | 6.11 µm | **8.91 µm** | 45.3 % |

孤兒點比例幾乎完全決定分數（ρ ≈ −0.93）。D2 的非配對與 query 空間重疊，NBLAST
只能靠形狀分辨，海綿效應才發動。

> ⚠️ **必須在論文揭露**：D1 的負例是人工挑的、空間上較遠；D2 的是自動產生、較近。
> 因此 D1 與 D2 的直接比較**部分反映負例挑選方式**。海綿效應本身在 D2 內部
> 獨立成立，不依賴這個跨組比較。

### 為什麼 Strahler 加權是對的藥

| | 真配對 | 假配對 | AUC |
|---|---|---|---|
| **D2 soma 距離** | **35.4 µm** | 108.2 µm | **0.801** |
| D1 soma 距離 | 73.7 µm | 161.4 µm | 0.713 |

在 113 組 NBLAST 分不開的 D2 案例中，soma 距離 AUC **0.784**（p = 1.9e-18）；
D1 的 6 組則無效（0.535）。

**加入 soma 後的交叉驗證 AUC**：D2 由 0.814 → **0.876**（錯誤率 **−33.3 %**）；
D1 **−0.001（無效）**。

**NBLAST 為何用不到 soma**：等權求和下，以 1 µm 重採樣後 soma 10 µm 鄰域僅佔點雲
**0.24 %（D2）/ 0.72 %（D1）**——絕對點數兩組相同（12 vs 13），差別全在分母。

**關鍵區分（重要，容易誤解）**：soma 有效**不是因為骨幹的幾何比較可靠**。實測顯示
骨幹（高 Strahler 階）的孤兒點 AUC 0.699 **低於**末梢的 0.801。soma 之所以有用，
是因為它是**位置地標**——密集的 EM 團可以在幾何上假裝「附近有點」，但假裝不了
「我的胞體在這個位置」。

## 4. ⚠️ 已被資料否證的七個假設（不要重蹈覆轍）

這些都曾看似合理，但實測不成立。**不要寫進論文，也不要重新提出。**

| 假設 | 否證依據 |
|---|---|
| D2 神經局部堆疊更密 | 每單位佔用體積的 cable 兩組相同（0.218 µm/µm³，AUC 0.57） |
| D2 自我重疊更嚴重（作為獨立性質） | 未控制 AUC 0.788 → 依 cable 長度配對後 **0.501** |
| D2 沒有明顯主軸，導致 NBLAST 角度項失效 | 慣量比 r31 AUC 僅 0.61；切向量集中度無差異（0.537, p = 0.32）；與配對難度無關聯 |
| 同組神經彼此重疊高使 D2 難分 | 無條件比較時反而 D1 較高（0.0055 vs 0.0005）；條件在同一主腦區才是 D2 高 |
| **D2 的 cable 長 → soma 被稀釋 → NBLAST 差** | D2 組內依 cable 分箱，AUC 為 0.624 / 0.862 / 0.890 / 0.848——**最短的一箱最差，方向相反** |
| D2 較難是因為負例經 prescreening 篩過 | 兩組非配對通過三層篩選的比例 **91.0 % vs 94.4 %** |
| 骨幹（高 Strahler）較不易被密集 EM 吸收 | 骨幹孤兒 AUC 0.699 < 末梢 0.801；最密四分位骨幹衰退更快 |

另外，「雙向平均或自比對正規化可以消除海綿效應」也不成立：
forward ρ +0.602 → 雙向平均 +0.572 → 官方 +0.574。原因是自比對正規化除以
`S(A,A)`，只與 query 有關，完全不涉及 target 端的偏差。

## 5. 程式與執行

```bash
conda create -n nblast python=3.10 -y && conda run -n nblast pip install navis
conda run -n nblast python analysis_dense_vs_projection/run_nblast_official.py --emit-figure-csv
```

## 6. 方法上的五個陷阱

1. **不要把 FC 與 EM 混在一起比形態。** 同一顆神經在 EM 量到的 cable 是 FC 的
   1.5 倍（線段中位 0.35 µm vs 4.54 µm），但空間跨度幾乎相同（0.97）——差的是
   追蹤精細度。所有骨架比較都在各資料庫內部做，兩邊都重現才採信。
2. **佔比的分母要含 `other`。** 58 個 neuropil 總和 + `other` = `volume`，
   48 633 筆 100 % 吻合。`other`（纖維束等）佔比兩組本就不同（D1 0.225 vs
   D2 0.161），排除它會把 `other` 多的那組灌大。「前兩腦區合計」排除 other 時
   AUC 0.716、含 other 時掉到 0.557，**不可作為準則**。
3. **密度指標要掃尺度。** 1 µm 重採樣搭配 2 µm 格子時 cable 幾乎不會重複經過同一格，
   指標飽和在 1 而測不出東西。`s03` 因此掃 4 / 8 / 16 µm 並加上三視圖投影。
4. **`neuron1x1Coding_Ver2.csv` 只有 FlyCircuit**（48 633 筆全是 FC id），且其數值是
   與 cable 長度成正比的**點數**（volume / cable ≈ 20 µm⁻¹，Spearman 0.906），
   不是解剖體積。
5. **NBLAST 分數只用 `run_nblast_official.py` 的輸出。** 理由見 §3。

## 8. 論文可用的論證骨架

1. D1 以 MB 為錨點人工標定，解剖同質（92 % 的 MB 與 DFP 各佔 ≥ 5 %，僅 4 個主腦區）；
   D2 以 prescreening 擴充，橫跨 12 個主腦區。
2. 兩組形態的主要差異是神經突總長度（2.8×，兩個資料庫一致），加上一條獨立的佔位
   拓撲軸；局部密度、自我重疊、形狀各向異性在控制大小後皆不成立。
3. 官方 NBLAST 在 D2 上 precision 僅 0.636（D1 為 0.907），27.3 % 的非配對達到
   真配對水準。
4. 主因是 hemibrain 側的海綿效應（ρ = +0.574；最密四分位 62.5 %）。已排除
   prescreening 強度與候選池密度變異兩個競爭解釋。
5. 人類以 soma 位置排除這些案例（在混淆案例中 AUC 0.784），而 NBLAST 給 soma 的
   權重僅 0.24 %。加入 soma 使 D2 錯誤率下降 33 %，D1 無變化。
6. MorphoMatcher 以 Strahler 階加權使 soma 與初級神經突取得最高權重，正是為了取用
   這個 NBLAST 結構上無法表達的線索。
