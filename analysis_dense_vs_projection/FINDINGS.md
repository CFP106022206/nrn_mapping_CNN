# 結論與支撐數據

所有數字出自 `results/`。FC = FlyCircuit，EM = hemibrain。中位數 [四分位距]；
AUC 為該描述子單獨使用時的可分離度（0.5 = 隨機）；p 為 Mann-Whitney U 雙尾。

**NBLAST 分數一律為 `run_nblast_official.py` 的輸出**（navis + 官方 `smat.fcwb`，
dotprops k=5、1 µm 重採樣、雙向平均且自比對正規化）。

**佔比的分母含 `other`**（= `volume`），也就是「佔該神經總重建量的百分之多少」。

## 1. 兩組的起源

D1 以蕈狀體為錨點人工標定；D2 其後以 stage-1 prescreening（`candidate_matching.py`：
質心距離 ≤ 100 µm、轉動慣量比 (r21,r31) 距離 ≤ 0.4、rod/disk 主軸一致）擴充。

**D1 的解剖同質性**（`s06`）：

| 條件 | D1 (n=103) | D2 對照 (n=147) |
|---|---|---|
| `mb_4` 或 `dfp_5` 在前兩名腦區 | **100.0 %** | 51.0 % |
| `mb_4` 在前兩名 | 97.1 % | 15.0 % |
| **`mb_4` 與 `dfp_5` 各佔總體積 ≥ 5 %** | **92.2 %** | 21.8 % |
| 前兩名剛好是 {`mb_4`, `dfp_5`} | 85.4 % | 13.6 % |
| 主腦區種類數 | **4** | **12** |

D1 中位佔比：`mb_4` 34.8 %、`dfp_5` 31.4 %、合計 68.4 %。93.2 % 為同側投射
（非跨半腦）。**注意**：仍有 8.7 % 的 D1 第二腦區佔比 < 10 %，不能說「全部都跨兩腦區」。

DFP = dorsofrontal protocerebrum（細分為 SDFP / IDFP）。MB↔DFP 的細胞型別歸屬
（MBON / DAN 等）本分析無法判定，需另行確認。

## 2. 形態差異的主軸是**大小**

| 描述子 | D1 | D2 | AUC | p |
|---|---|---|---|---|
| Cable length, FC | 1 722 µm | **4 817 µm** | **0.905** | 4e-28 |
| Cable length, EM | 2 318 µm | **6 584 µm** | 0.819 | 2e-26 |
| Branch points, FC | 74 | **230** | 0.886 | 1e-25 |
| 第二 compartment 佔比, FC | **0.325** | 0.162 | 0.884 | 5e-25 |

`cable_length`、`n_branch_points`、`n_tips`、`occupied_volume` 相互 Spearman
**≥ 0.96**，是**同一個大小軸**。扣除 cable 長度後，分支數的殘餘判別力僅 AUC 0.569
（FC，p = 0.063），且方向相反（D1 每單位 cable 的分支略多）。

**佔位拓撲是第二條獨立軸**：`side_top2` AUC 0.884，依 cable 長度 1:1 配對後
（±25 %）仍有 **0.808**。組內 log(cable) 與佔位分散度的相關 |ρ| ≤ 0.35。

**可引用的納入條件**（`s07`，10-fold × 10 重複，門檻在每個訓練 fold 內重擬合）：
cable ≥ 2 000 µm **且** 第二 compartment 佔比 ≤ 0.32 → balanced accuracy
**0.881 ± 0.071**（precision 0.91 / recall 0.93）。

## 4. ⭐ 失效機制：hemibrain 側的「海綿效應」

NBLAST 對 query 的每個點取 target 的最近鄰計分。**當 target 是填滿緊緻體積的高密度
樹突叢時，query 的任何一點都能找到近鄰，分數被結構性推高**，與形狀是否相符無關。

海綿效應需要兩個條件同時成立：**線材夠密**，且**縮在夠小的範圍**（才會整團壓在
query 上）。因此最能捕捉它的指標是把兩者合在一起量的**凸包密度**。

### 主要證據：凸包密度 `cable_per_hull_um2` = 總 cable 長度 / 凸包體積（µm/µm³）

D2 的 414 組非配對中，NBLAST 分數與 **hemibrain 側**凸包密度的 Spearman
**ρ = +0.639**（p = 5.6e-49）。依此四等分：

| 四分位 | 假配對分數中位 | **達真配對水準的比例** |
|---|---|---|
| 1（最稀疏） | −0.048 | **1.9 %** |
| 2 | 0.106 | 14.4 % |
| 3 | 0.232 | 34.6 % |
| 4（**最密**） | **0.331** | **68.9 %** |

（真配對分數中位 0.336）**最密與最稀疏的四分位差 36 倍。**

**穩健性**：凸包對離群分支敏感是常見疑慮，但實測不成立——剔除距質心最遠的
1 / 5 / 10 % cable 後重算，ρ 為 +0.643 / +0.657 / +0.644（完整凸包 +0.637），
各版本相關 0.94–0.99，凸包體積中位僅縮小 4 %。

`fill_ratio`（佔用體積 / 凸包體積，無量綱）給出幾乎相同的結果：ρ = +0.643，
1.9 % → 69.2 %。它純粹在量「這團有多實心」，可作為佐證。

### 次要證據：佔用格密度 `revisit_r16um`

= 總 cable 長度 /（被佔用的 16 µm 格子數 × 16 µm）。無單位，**1.0 = 每格恰被
直直穿過一次**。它只量「神經實際碰到的空間有多擠」，不含凸包的形狀資訊。

ρ = **+0.574**（p = 1.2e-37），四分位 **3.8 % → 62.5 %**。

兩者相關 0.785——**相關但不等同**，凸包版多出來的正是「形狀緊緻度」，這也是它
預測力較高的原因（+0.639 vs +0.574）。`revisit` 的價值在於它**不依賴凸包假設**，
因此作為敏感度分析：結論不隨密度的定義方式改變。

多尺度佐證：`revisit_r4um` +0.490、`revisit_r8um` +0.524、`revisit_r16um` +0.574
——訊號隨尺度單調增強，細尺度（1–2 µm）因 cable 幾乎不重複經過同一格而飽和。

### 效應完全在 hemibrain 側

| 描述子 | **EM 側 ρ** | FC 側 ρ |
|---|---|---|
| **`cable_per_hull_um2`** | **+0.639** | — |
| `fill_ratio` | +0.643 | — |
| `revisit_r16um` | **+0.574** | −0.052 |
| `overdraw_2d_mean` | +0.538 | +0.103 |
| `hull_volume_um3` | **−0.457** | −0.477 |
| `cable_length_um` | +0.337 | −0.051 |

FC 側全部接近 0 且不顯著。`hull_volume` 的負號（凸包越小分數越高）正是「緊緻」
這一半條件的直接體現。

少數 EM 神經成為「hub」，吸走大量假陽性：`1640922516`（19 620 µm cable、
3 558 分支、凸包密度高）單獨吸引 6 組高分假配對；`947573616`（27 778 µm、
6 324 分支）4 組。

### 已排除的競爭解釋

| 解釋 | 檢驗 | 結論 |
|---|---|---|
| D2 的負例被 prescreening 篩得比較難 | 兩組非配對通過三層篩選的比例 **91.0 % (D1) vs 94.4 % (D2)** | ❌ 不成立 |
| D1 的 EM 池密度比較均勻 | 變異係數 **0.536 (D1) vs 0.528 (D2)**，95/5 分位比 3.4× vs 4.1× | ❌ 不成立 |
| 雙向平均 / 自比對正規化可消除 | forward ρ +0.602 → 雙向平均 +0.572 → 官方 +0.574 | ❌ 幾乎無效果 |

**自比對正規化為何無效**：`S(A,A)` 只與 query 有關，完全不涉及 target，而偏差來自
target 端。可能的修正方向是對 target 也正規化（除以其對隨機神經的期望分數）。

### D1 為何免疫

不是因為池子均勻，而是**D1 的非配對根本不在同一個位置**（`s10` 第 7 項）：

| | 真配對 NN 中位 | **假配對 NN 中位** | 假配對 >10 µm 孤兒點 |
|---|---|---|---|
| **D1** | 5.63 µm | **44.25 µm** | **98.7 %** |
| **D2** | 6.11 µm | **8.91 µm** | 45.3 % |

孤兒點比例幾乎完全決定分數（D1 ρ = −0.936、D2 ρ = −0.924）。D2 的非配對與 query
空間重疊（NN 8.91 µm，真配對 6.11 µm），NBLAST 只能靠形狀分辨，海綿效應才發動。

⚠️ **必須揭露**：D1 的負例是人工挑的、空間上較遠；D2 的是自動產生、較近。因此
**D1 與 D2 的直接比較部分反映負例挑選方式**。海綿效應本身在 D2 內部獨立成立，
不依賴這個跨組比較。

## 5. 人工判定用 soma，而 NBLAST 看不到

| | 真配對 | 假配對 | AUC | p |
|---|---|---|---|---|
| **D2** | **35.4 µm** | 108.2 µm | **0.801** | 2.0e-40 |
| D1 | 73.7 µm | 161.4 µm | 0.713 | 7.8e-08 |

在 113 組 NBLAST 分不開的 D2 配對中，soma 距離的 AUC 為 **0.784**（p = 1.9e-18）；
D1 的 6 組則無效（0.535, p = 0.78）。

**加入 soma 後的交叉驗證 AUC**（5-fold × 20）：

| | NBLAST | soma | **NBLAST + soma** | 增益 | 錯誤率 |
|---|---|---|---|---|---|
| D1 | 0.9665 | 0.7139 | 0.9657 | −0.0008 | **−2.4 %** |
| **D2** | 0.8142 | 0.8010 | **0.8761** | **+0.0619** | **−33.3 %** |

**NBLAST 為何用不到 soma**：等權求和下，以 1 µm 重採樣後 soma 10 µm 鄰域僅佔點雲的
**0.24 %（D2）與 0.72 %（D1）**——絕對點數兩組幾乎相同（12 vs 13），差別全在分母。
骨幹同樣被稀釋：最高 Strahler 階的 cable 佔比 D2 為 2.9 %（FC）與 2.2 %（EM），
D1 為 5.4 % 與 6.0 %；而骨幹的**絕對**長度在 EM 上兩組幾乎相同（149.5 vs 146.7 µm，
1.02×），總 cable 卻差 2.84×。

⚠️ **不能寫成劑量反應**：D2 組內依 cable 長度四等分，NBLAST 的 AUC 為
0.624 → 0.862 → 0.890 → 0.848（最短的一箱最差）。**cable 越長 NBLAST 反而越好**，
因此「D2 的 cable 長所以 soma 被稀釋所以 NBLAST 差」這條因果鏈**不成立**。
稀釋是**與大小無關的結構性盲點**，不是錯誤率的驅動因素。

## 6. 論文可用的論證骨架

1. D1 以 MB 為錨點人工標定，解剖同質（92 % 的 MB 與 DFP 各佔 ≥5 %，僅 4 個主腦區）；
   D2 以 prescreening 擴充，橫跨 12 個主腦區。
2. 兩組形態上的主要差異是神經突總長度（2.8×，兩個資料庫一致），加上一條獨立的
   佔位拓撲軸；局部密度、自我重疊、形狀各向異性在控制大小後皆不成立。
3. 官方 NBLAST 在 D2 上 precision 僅 0.636（D1 為 0.907），27.3 % 的非配對達到
   真配對水準。
4. 主因是 hemibrain 側的海綿效應：非配對分數與 EM 凸包密度 ρ = **+0.639**，最密
   四分位 **68.9 %** 的非配對達真配對水準（最稀疏僅 1.9 %）。佔用格密度給出同向
   但較弱的結果（+0.574），顯示結論不依賴密度的定義方式。已排除 prescreening
   強度與候選池密度變異兩個解釋。
5. 人類以 soma 位置排除這些案例（在混淆案例中 AUC 0.784），而 NBLAST 給 soma
   的權重僅 0.24 %。加入 soma 使 D2 錯誤率下降 33 %，D1 無變化。
6. MorphoMatcher 以 Strahler 階加權使 soma 與初級神經突取得最高權重，正是為了
   取用這個 NBLAST 結構上無法表達的線索。
